🔍 Grep
FlagAction
-r / -RRecursive (R follows symlinks)
-i / -v / -cCase-insensitive / Invert / Count
-l / -LFiles with match / Files without
-oPrint only matching part
-E / -PExtended regex / Perl regex (\d \w \s)
-A n / -B n / -C nLines after / before / around match
--exclude-dir={.git,vendor}Skip directories in recursive search
# Extract IPs from logs
grep -oP "\b\d{1,3}(\.\d{1,3}){3}\b" access.log
# Recursive search excluding dirs
grep -r --exclude-dir=node_modules "pattern" /etc/
🌊 Sed
CommandAction
s/old/new/Replace first match per line
s/old/new/gReplace all matches per line
-i (GNU) / -i '' (BSD)In-place file edit
5s/old/new/Replace only on line 5
10,20s/old/new/gReplace in line range 10–20
/pat/s/old/new/gReplace on lines matching /pat/
/pat/dDelete lines matching pattern
5d / 10,20dDelete line 5 / Delete range 10–20
-E 's/(.*)\s(.*)/\2 \1/'Capture groups: swap two words
# Reverse lines (tac equivalent)
sed -n '1!G;h;$p' file
# Double-space a file
sed 'G' file
📊 Awk
Built-in Variables
  • $0 entire line · $1..$NF fields · NF field count
  • NR line number (global) · FNR line number (per-file)
  • FS/OFS input/output field separator · RS/ORS record separators
CommandAction
-F',' '{print $1, $NF}'Parse CSV: first & last column
'$5 > 90'Filter: lines where col 5 > 90
'{s+=$5} END {print s/NR}'Average of column 5
'{ip[$1]++} END {for(k in ip) print k,ip[k]}'Frequency count (e.g. hits per IP)
'!seen[$0]++'Deduplicate lines (preserve order)
'NR==10,NR==20'Print lines 10 through 20
BEGIN{OFS=","} {print $1,$2}Change output separator to comma
