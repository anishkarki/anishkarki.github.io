Bash Options & Params
Safety Flags (shorthand: set -euo pipefail)
set -o errexit / -e Exit immediately if any command returns non-zero status
set -o nounset / -u Exit if script references an undefined/unset variable
set -o pipefail Pipe status matches rightmost command that failed
set -o xtrace / -x Trace execution: Print commands to stderr before executing
Parameter Expansion (FILE="/opt/app/src/server.ts")
${TIMEOUT:-30} Returns 30 if TIMEOUT is unset/empty (Default)
${DB_URL:?Need DB} Fails script with Need DB error if unset (Assert)
${FILE/server/client} Replace first match: "/opt/app/src/client.ts"
${FILE//s/z} Replace all matches: "/opt/app/zrc/zerver.tz"
${FILE#*/} Trim front short: "opt/app/src/server.ts"
${FILE##*/} Trim front long: "server.ts" (file basename)
${FILE%/*} Trim back short: "/opt/app/src" (parent directory)
${FILE%%/*} Trim back long: ""
Redirection & Streams
Syntax / Redirection Behavior Description

cmd1 |& cmd2 Pipe both stdout and stderr of cmd1 to cmd2

(cd dir && cmd) Execute in subshell without modifying parent directory

S="workspace"
tmux has-session -t $S 2>/dev/null
if [ $? != 0 ]; then
  tmux new-session -d -s $S -n "editor"
  tmux send-keys -t $S:1 "vim ." C-m
  tmux new-window -t $S -n "logs"
  tmux split-window -h -t $S:2

  tmux select-window -t $S:1
fi
tmux attach-session -t $S

Awk Arrays & Aggregations
Arithmetic Logs Aggregations
# Sum column 5:
awk '{ sum += $5 } END { print sum }' file.log
# Average column 5:
awk '{ s += $5 } END { print s/NR }' file.log
# Find Min/Max of column 1:
awk 'NR==1 {min=max=$1} 
     $1>max {max=$1} 
     $1<min {min=$1} 
     END {print "Min:", min, "Max:", max}'
Associative Arrays (Hash Maps)
# Count frequency of column 1 (e.g. log IPs):
awk '{ hits[$1]++ } END { 
  for (ip in hits) print ip, hits[ip] 
}' access.log | sort -rn -k2
