Parameter Expansion (FILE="/opt/app/server.ts")
${V:-30}Returns value 30 if V is unset/empty
${V:?msg}Fails script with msg error if V unset
${FILE/s/c}Replace first: "/opt/app/cerver.ts"
${FILE//s/z}Replace all: "/opt/app/zerver.tz"
${FILE#*/}Trim front short: "opt/app/server.ts"
${FILE##*/}Trim front long: "server.ts" (basename)
${FILE%/*}Trim back short: "/opt/app" (dirname)
${FILE%%/*}Trim back long: ""

Vim Block & Registers
Visual Block Multi-line (Ctrl + v)
  • Column Prepending: Ctrl+v select vertical block ➔ I (capital) ➔ Type text ➔ Esc Esc
  • Column Appending: Ctrl+v select block ➔ $ (end of line) ➔ A ➔ Type ➔ Esc Esc
  • Replace Block: Select block ➔ c ➔ Type ➔ Esc Esc
  • Visual Command Filter: Select lines visually ➔ :!sort (runs shell sort filter on block)
Vim Register System (specified with "reg)
RegisterType / Use Case Target
""Unnamed: default bucket for cut/delete/yank
"0Yank buffer: holds last yanked text (prevents delete/cut overrides)
"+ / "*System Clipboard interface (syncs with OS clipboard)
"_Black hole: discards deletes entirely (doesn't overwrite registers)
"/Read-only: contains pattern from last slash search
". / ":Read-only: last inserted text / last command line
"=Expression register (math calculator: Ctrl+r =5*20)
